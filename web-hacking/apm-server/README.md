# APM Server Practice

## Overview

Apache, PHP, MySQL(APM) 환경을 직접 구축하고 회원가입 및 로그인 기능을 구현한 프로젝트이다.

웹 서버 구축부터 데이터베이스 연동, Session과 Cookie를 이용한 사용자 인증까지 웹 애플리케이션의 기본적인 동작 과정을 직접 구현해 보았다.

---

## What I Implemented

- APM(Apache, PHP, MySQL) 환경 구축
- PHP와 MySQL 연동
- 회원가입 및 로그인 기능 구현
- Session을 이용한 로그인 유지
- Cookie를 이용한 사용자 인증

---

## Environment

- Ubuntu 26.04 Server
- Apache2
- PHP
- MySQL
