# APM Server Practice

## Overview

Ubuntu 환경에서 Apache, PHP, MySQL(APM)을 구축하고
회원가입 및 로그인 기능을 구현한 프로젝트입니다.

## Features

- APM(Apache, PHP, MySQL) 환경 구축
- PHP와 MySQL 연동
- 회원가입 및 로그인 기능 구현
- Session을 이용한 로그인 유지
- Cookie를 이용한 사용자 인증

## Environment

- Ubuntu 26.04 Server
- Apache2
- PHP
- MySQL

## Learning

- Apache, PHP, MySQL의 역할 이해
- PHP와 MySQL 연동 방법
- Session과 Cookie를 이용한 인증 방식
- 로그인 시스템의 기본 동작 원리
